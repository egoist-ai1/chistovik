# Чистовик

Удаляет программы Windows 10/11 вместе с остатками, держит удалённое в карантине, откатывает любое изменение и управляет настройками системы (режимы, питание, автозагрузка, службы, твики реестра, окна, мониторинг).

Состояние: этап M0 (фундамент). Приложения ещё нет. План — [docs/PLAN.md](docs/PLAN.md), прототип интерфейса открывается в браузере: `docs/prototype/chistovik-prototype.html`.

## Снимки экранов

Режим `--snapshots <папка>` рисует каждый экран и диалог в PNG на демонстрационных данных (в кадре есть пометка «Демонстрационные данные»; реестр, службы и файлы системы не читаются и не меняются). Окно не показывается: оно создаётся за пределами экрана, без кнопки на панели задач, с флагом WS_EX_NOACTIVATE и без активации, поэтому фокус не забирается.

```
dotnet run --project src/Chistovik.App -c Release -- --snapshots "C:\Temp\chistovik-shots"
```

Имя файла: `<экран>[-состояние]_<ширина>x<высота>_<dpi>.png`, например `startup_1280x800_96.png`, `services-empty_1280x800_96.png`, `dialog-conflicts_auto_192.png`. Размеры 1280×800 и 1920×1080, DPI 96 (100 %) и 192 (200 %). Состояния: `empty`, `loading`, `error`, `viewonly` (режим просмотра), `partial` (частичный результат). Тема одна, Signal (тёмная), суффикса темы нет. Ход работы пишется в `snapshots.log` в той же папке; код выхода 0 — все снимки сохранены. Перечень снимков задаёт `src/Chistovik.App/Snapshots/SnapshotPlan.cs`, он проверен юнит-тестом.
