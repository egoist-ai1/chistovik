# Чистовик — правила проекта

Windows-приложение: поиск и удаление программ с остатками, карантин и откат, центр управления системой (режимы, питание, автозагрузка, службы, твики реестра, окна, мониторинг). Общие правила — из `C:\Users\Egoist\.claude\CLAUDE.md`; здесь только специфика. План — [docs/PLAN.md](docs/PLAN.md), прототип (вся логика симулирована) — [docs/prototype/chistovik-prototype.html](docs/prototype/chistovik-prototype.html).

## Границы безопасности (не нарушать, не обсуждать)
- `Chistovik.Core.Policy` — единственное место, которое решает «можно». Данные зон и защищённых объектов зашиты в сборку, не настраиваются.
- В `Chistovik.Agent` нет операции «удалить файл». Только перенос в карантин и очистка самого карантина.
- Системные зоны (WinSxS, DriverStore, WindowsApps, Installer, Windows, NonRemovable) закрыты всегда, в том числе в экспертном режиме.
- Не отключаем и не предлагаем отключать Defender, UAC, SmartScreen, защиты процессора, проверку подписи драйверов. Сеть и DNS хоста не меняем.
- Не распознано точно — только показываем, не меняем.
- Любой новый тип запроса к агенту добавляется в белый список вместе с негативным тестом.
- Негативные тесты (`tests/Policy.Negative`) блокируют коммит. Не ослаблять тест ради зелёной сборки.
- Код Policy, Agent и отката пишет и проверяет не одна модель: ревью делает другая.

## Решения владельца (22.10.2026)
Нет устройства ARM64 (собираем, не проверяем на железе); нет постоянной фоновой программы; ПК однопользовательский; диски NTFS; подпись SignPath позже; два процесса (App без прав + Agent с правами по UAC); защита служб по правилам-классификатору, а не по списку.

## Решения владельца (24.10.2026)
- Релиз 0.1 = автозагрузка + журнал + откат, твики реестра, питание и режимы, службы и задачи (то есть M1 и M2 вместе).
- Код открытый, лицензия GPL-3 (нужно для бесплатной подписи SignPath). Репозиторий публичным не делаем без «да»; файл LICENSE добавить до релиза 0.1.
- Режим «Эксперт» нужен: спорные остатки (уровень ExpertOnly) удаляются с отдельным подтверждением на каждый объект, всё через карантин. Deny не снимается никаким флагом.
