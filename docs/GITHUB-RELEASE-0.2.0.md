# Чистовик 0.2.0

Первый публичный выпуск. Центр управления Windows 10/11: удаление программ с остатками, карантин, откат любого изменения, управление настройками системы. Интерфейс на русском.

First public release of Chistovik, a Windows 10/11 uninstaller and system settings manager with a journal and undo. The UI is in Russian.

## Скачать

| Файл | Система |
|---|---|
| `Chistovik-0.2.0-x64.msi` | Windows 10 1809+ и Windows 11 на x64 |
| `Chistovik-0.2.0-arm64.msi` | Windows 11 на ARM64 |
| `SHA256SUMS.txt` | контрольные суммы |

Установка: `msiexec /i Chistovik-0.2.0-x64.msi` (или двойной щелчок). .NET ставить не нужно. Обновление поверх 0.1.x сохраняет данные. Проверить файл: `Get-FileHash .\Chistovik-0.2.0-x64.msi -Algorithm SHA256` и сравнить с `SHA256SUMS.txt`.

## Что умеет

- Чистка с объяснением по каждому объекту и превью до применения.
- Удаление программ вместе с остатками; удалённое сначала в карантине.
- Автозагрузка, службы и задачи (часть служб и задач защищена и не меняется никогда).
- Режимы, схемы питания и их параметры, 46 проверенных твиков реестра.
- Журнал с откатом любого изменения.
- Права администратора нужны только агенту и запрашиваются через UAC; без них приложение работает в режиме просмотра.

## Что изменилось с 0.1.x

- Режим применяет твики, даже если схемы питания нет на устройстве (Modern Standby): схема пропускается, об этом сказано в результате.
- Программы с запретом удаления (`NoRemove`) показываются только для просмотра.
- Тип значения в реестре, отличный от ожидаемого, не перезаписывается молча.
- Откат пересчитывается и после прерванного отката; журнал открывается без прав записи при работающей службе.
- Твики учитывают сборку Windows и редакцию.
- Интерфейс: настоящие значки приложений, окна от 900×600, масштаб до 200 %, понятные сообщения об ошибках.

## Что проверено

- Автотесты (политика, ядро, Windows API, интерфейс, интеграция): зелёные.
- 115 снимков интерфейса, размеры 900×600 – 1920×1080, масштаб 100–200 %.
- Windows Sandbox (Windows 11 Enterprise, сборка 26100): применение и откат каждого твика, службы, задачи, диск, реестр, удаление программ, установка, удаление и обновление MSI.

## Что не проверено

- Windows 10: образа не было, проверялось по документации.
- Запуск на ARM64: пакет собран и проверен по заголовкам файлов, но не запускался.
- Modern Standby на реальном ноутбуке; два монитора с разным масштабом.
- Живой UAC и второй сеанс пользователя.
- Часть твиков помечена «не проверено на живой системе»: поведение Windows после них зависит от сборки.

Перед массовым применением твиков создайте точку восстановления Windows: откат Чистовика возвращает прежние значения, но не заменяет резервную копию.

## Конфиденциальность

Программа не передаёт данные: в ней нет сетевого кода, телеметрии и проверки обновлений.
