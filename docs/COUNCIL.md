# Деинсталлятор Windows: итог совета и план (22.10.2026)

Рабочее имя идеи: **Egoist Clean**. Основа: досье `01-досье-фактов.md`, четыре независимых ревьюера (два раунда спора).

Состав совета: скептик рынка (Opus), продукт/рост/дизайн (Opus), системный инженер Windows (Fable), безопасность/право/дистрибуция (Fable). Три исследователя (Sonnet) собрали факты. Метки в досье: [П] — проверено по первоисточнику, [В] — вторичный источник.

## 1. Вердикт совета

Идти, но **урезанным**. Программа «удаление + очистка + оптимизация + 100 % покрытие» не получится у одного разработчика и не имеет рыночной ниши: BCU бесплатен и открыт, Revo стоит 770 ₽, очистку берут Storage Sense и PC Manager, подписать код из России почти негде.

Сильная позиция одна: **открытый, проверяемый деинсталлятор с карантином, откатом, чеком операции и открытым бенчмарком, который считает не только найденные остатки, но и ложные удаления.** Такого бенчмарка на рынке нет: единственный найденный (Uninstalr) сделан автором конкурента, один прогон, поиск по имени, награждает агрессивное удаление.

Все четверо согласились: **«100 %» убрать из продукта и маркетинга**. Критерий PUA от Microsoft прямо считает преувеличенные заявления сигналом нежелательной программы.

## 2. Честное обещание вместо «100 %»

1. Удаляем 100 % того, что программа **зарегистрировала** (MSI-таблицы, манифест AppX, ARP) и что мы **видели при установке** под наблюдением.
2. Остальное показываем с уровнем уверенности и причиной; решает пользователь.
3. Всё удалённое нами лежит в карантине N дней и восстанавливается байт-в-байт (хеш, ACL, атрибуты).
4. Цифры из открытого корпуса: полнота по уровням, **0 ложных удалений на контрольных парах «один вендор — два продукта»**, верность отката.
5. Необратимо и не обещаем: действия чужого деинсталлятора, удаление AppX (только переустановка), WSL, операции через PendingFileRenameOperations. Интерфейс говорит это прямо.

## 3. Уровни уверенности остатков

| Уровень | Что это | Политика |
|---|---|---|
| L0 | Задекларировано (MSI Component/Registry, AppX-манифест, ARP InstallLocation) | удаляем |
| L1 | Наблюдено ETW во время установки под наблюдением | удаляем |
| L2 | Структурно: внутри InstallLocation, цель ярлыка/службы/Run внутри дерева | удаляем |
| L3 | Эвристика имени, издателя, пути | только по явной галочке с предпросмотром |
| L4 | Спорное: общий вендор, SharedDLLs > 1, чужой InstallLocation, рантаймы | никогда |

Запретные зоны (вшиты, не настраиваются): WinSxS, DriverStore, WindowsApps, C:\Windows\Installer, Package Cache; `SfcIsFileProtected`; владелец TrustedInstaller; Edge/WebView2/NonRemovable — только показать.

## 5. Архитектура

- C#/.NET (LTS), WPF, CsWin32; ETW через `Microsoft.Diagnostics.Tracing.TraceEvent` (MIT). Два артефакта: win-x64, win-arm64.
- UI без прав; отдельный повышенный «движок» по UAC, один экземпляр, named pipe с ACL на SID вызывающего, гаснет по простою. Не служба.
- Порядок операции: проверенная точка восстановления → снимок (USN + экспорт затронутых ключей) → остановка служб/задач, закрытие процессов через Restart Manager → штатный деинсталлятор → дифф после → кандидаты с уровнями → карантин (перемещение на том, манифест, RegSaveKey + .reg) → автоочистка карантина.
- Защита от TOCTOU: проверка reparse points и junction перед каждым файловым действием.
- Данные: SQLite — `Package`, `Artifact`, `Evidence`.
- Тесты: корпус 60–100 программ (MSI, WiX Burn, InstallShield, NSIS, Inno, Squirrel, ClickOnce, MSIX, Electron, portable, Steam, OEM-драйвер), пары «один вендор — два продукта» как канарейки, истина — независимый снимок файлов и реестра до/после; Win10 22H2, Win11 23H2/24H2/25H2, Home и Pro; ARM64 на физическом устройстве или Azure. Стоимость тестов 30–40 % всей работы, постоянно.

## 6. Доверие, подпись, лицензия

- Лицензия: **GPL-3.0-or-later** (решить до первого коммита; смена после релиза сбрасывает подпись и репутацию). Правила BleachBit (CleanerML) — GPL-3.0+, Winapp2 — CC BY-SA 4.0, BCU — Apache-2.0 (нужен NOTICE).
- Подпись: основной путь — **SignPath Foundation** (бесплатно для OSI-лицензии, сборка в CI, издатель «SignPath Foundation»); в октябре 2026 малым проектам отказывают за «малую публичную видимость». Страховка — ИП + GlobalSign через LeaderSSL (~24 900 ₽/год, но GlobalSign уже отзывал сертификаты российских компаний). Certum, Sectigo, DigiCert, Azure Artifact Signing для физлица из РФ недоступны.
- Без подписи: Smart App Control блокирует без обхода (оценочно 10–20 % машин Win11), SmartScreen обходится через «Всё равно запустить».
- Дистрибуция: winget, Scoop, GitHub Releases, портативная сборка; Microsoft Store — запасной канал (кейс отказа физлицу из РФ).
- Антивирусы: BCU ловит Wacatac на неподписанных релизах. Меры: сухой прогон по умолчанию, без резидента и автозапуска, без пакеров и обфускации, без вызова PowerShell с длинными строками, без тихого режима в GUI; перед релизом VirusTotal, Microsoft WDSI, Kaspersky Allowlist, ESET.
- Деньги: Paddle, Stripe, Lemon Squeezy из РФ недоступны. Работают Boosty (11,7 %), Tribute, ЮKassa/Robokassa с самозанятостью. При GPL: донаты и платная «поддерживаемая сборка»; закрытый Pro несовместим с SignPath. Реестр Минцифры не окупится.

## 7. Дизайн (Egoist DS, режим Signal)

Лайм только для живого (идёт скан, идёт удаление, активна сессия наблюдения), не для «хорошо/плохо». Уверенность остатков передаётся ступенями графита, иконкой и словом-причиной («в пути есть ProductCode»). Пути, ключи, размеры — JetBrains Mono. Сетка приводки: кресты по углам области, индекс шага `01/04` (Инвентарь → Предпросмотр → Удаление → Чек), линейка только на реальной шкале, паспорт только в подвале чека и экспортного отчёта. Сетки нет в таблице инвентаря, диалогах, настройках. Экраны: инвентарь, карточка программы, предпросмотр, выполнение, чек, журнал и откат, карантин, запретные зоны и настройки. Состояния: предпросмотр с постоянной строкой «ничего не изменено», честный частичный откат («вернули 41 из 43»), ошибка «что случилось, в каком состоянии система, один следующий шаг».

## 10. Спор и как он разрешён

- **ETW: MVP, v1.5 или v2?** Инженер: ядро точности. Скептик и продукт: v2, потому что главный сегмент (переустановка уже стоящего ПО) наблюдением не покрывается. Безопасность: приемлемо, если сессия по кнопке, без резидента (+5 п. п. к риску меток). **Решение: v1.5, по кнопке.**
- **Платный Pro или GPL?** Продукт снял Pro: конфликт с SignPath. **Решение: GPL, донаты, платная поддерживаемая сборка.** Если цель — коммерция, отдельная схема: ИП + свой сертификат GlobalSign, тогда SignPath не нужен.
- **Срок MVP:** 9–14 нед (продукт, исходно) против 14–24 нед (инженер). Продукт признал, что не учёл стенд. **Решение: 16–24 нед со стендом.**
- **Шанс 10 000 установок:** 15 % против 30 % → 18 %.
- **Цель владельца неизвестна.** Для денег вердикт скептика: не идти. Для инструмента или репутации: идти урезанным.

## 11. Решения владельца

1. **Цель:** деньги, репутация/портфолио или собственный инструмент. От этого зависит всё остальное.
2. **Лицензия и подпись до первой строки кода:** GPL-3.0-or-later + заявка в SignPath, параллельно ИП и GlobalSign как страховка.
3. **Обещание:** без «100 %», без «ускорит»; только цифры открытого бенчмарка.
4. **Бенчмарк:** отдельный репозиторий, методика публикуется до релиза продукта, корпус открыт, проигрыши публикуются.
5. **Сбои без телеметрии:** добровольный экспорт чека (opt-in).

## 12. Проверить первым (дёшево)

1. Заявка в SignPath с готовым `CODE_SIGNING.md` и ссылкой на репозиторий бенчмарка, ответ до выбора архитектуры.
2. Запрос в LeaderSSL: оформляют ли ГлобалSign на ИП на НПД, условия при отзыве.
3. Страница стран Partner Center и политика SSL.com по RU (не открылись у ревьюера).
4. Прототип в VM: как Defender реагирует на массовые правки автозапуска и на ETW-сессию.
5. Реальные цифры загрузок Revo, Geek, BCU; обсуждения на Reddit, ru-board, OSZone (комментарии в Telegram недоступны).

## 13. Поправки к досье

- Разбор `UninstallString` только через `CommandLineToArgvW` неполон: незакавыченный `C:\Program Files\X\uninst.exe /S` режется по пробелам; нужен поиск самого длинного существующего префикса.
- CleanerML (BleachBit) — GPL-3.0-or-later, а не «необременён».
- Не подтверждено: имя политики RemoveDefaultMicrosoftStorePackages; «Microsoft не поддерживает чистку C:\Windows\Installer» (только ответы модераторов); KB 2563254 (только цитаты); причина кода 532 при удалении Edge на 24H2 (наблюдение пользователей).

## 14. Что не проверено

Все вероятности и сроки — оценки. Бенчмарк Uninstalr перепроверен только по его собственной методике. Telegram-корпус (3727 постов) смещён в сторону аудитории взломанных программ; комментарии и Reddit недоступны. Доступность Microsoft Store и сертификатов из РФ — по отдельным кейсам. Сам Social-демон был восстановлен переименованием устаревших локов `broker.lock` и `store/store.lock` (файлы `*.stale-20261022`).

## Приложение 2: решения владельца со стенда (22.10.2026) и версия прототипа 0.2

Прототип переименован в **«Чистовик»** (имя выбрано мной по просьбе «оригинальное подходящее», конфликтов в поиске не нашлось; сменить легко). Файл `chistovik-prototype.html` заменил `egoist-clean-prototype.html` в Artifact (версия 2); старый файл оставлен как v1.

**Общее.** Цель — инструмент для себя; первая версия — Windows 10, 11 и ARM64; распространение — сайт и GitHub; тема тёмная; язык только русский; пользователь продвинутый. Лицензия в «О программе» — GPL-3.0-or-later (по плану, не по ответу стенда).

**Экраны и решения.**
- Рамка: левая рейка. Первый запуск: один экран «Сканировать», запрос прав администратора сразу при запуске (без прав — режим просмотра), подсказки на месте и скрываемые.
- Инвентарь: таблица и карточка справа, первыми самые большие, защищённое видно с пометкой.
- Предпросмотр: дерево по категориям; заранее отмечено L0–L2; уровни только цветом и значком; точка восстановления спрашивается, один раз на операцию.
- Выполнение: конвейер из 7 шагов по горизонтали, полный журнал, отмена до шага «Деинсталлятор».
- Чек: документ-чек; «освобождено» только после проверки диска; JSON рядом с журналом.
- Журнал: группы по вендорам, хранение 90 дней, откат спрашивает (всё или выбранное).
- Карантин: корзины по срокам, 7 дней, без лимита, предупреждение при превышении порога (по умолчанию 4 ГБ).
- Защита: лесенка L0–L4, экспертам отдельный режим с UAC и ожиданием 10 секунд, объяснения с правилом и путём.
- Доверие: таблица соревнования, публикуем только после релиза, главное число — полнота.
- Оптимизация: список задач с выигрышем, включая службы и задачи планировщика (с пометкой риска), только вручную.
- Под наблюдением: три шага, только в экспертном режиме, итог — список изменений.
- Настройки: разделы слева, пять главных; меню проводника «Показать остатки в Чистовике»; уведомления только итоги.

**Моя трактовка, которую нужно подтвердить.** Экспертный режим открывает только общие компоненты вендоров (L3/L4). Системные зоны (WinSxS, DriverStore, WindowsApps, Installer, Windows, NonRemovable) остаются закрытыми всегда. Ответ стенда можно читать шире; я выбрал безопасную сторону.

**Что в прототипе симуляция.** Остатки строятся по шаблону, «освобождено» считается по манифесту, а не измеряется, UAC и точка восстановления нарисованы. Проверено синтаксисом и прогоном в jsdom (34 проверки), в живом браузере не открывалось.

## Приложение 3: центр управления системой, прототип 0.3 (22.10.2026)

Владелец принял имя «Чистовик» и просил максимум: интерактив, настройки, живые показатели, реестр, режимы, электропитание, перенос окон, плавность. Прототип расширен с деинсталлятора до центра управления. Артефакт: версия 3 по прежнему адресу.

**Что добавлено (раздел «Система» в навигации)**
- **Обзор.** Живые кривые процессора, памяти, диска и сети, оценка здоровья, время загрузки, плитки быстрых действий, рекомендации «что можно улучшить».
- **Режимы.** Шесть наборов: сбалансированный, работа, игровой, тихий, экономия батареи, максимум. Показывается список изменений до включения, откат одним нажатием.
- **Питание.** Планы, тонкая настройка от сети и от батареи (процессор, дисплей, сон, PCIe, USB), оценка влияния, добавление плана «Максимальная производительность». Команды `powercfg`.
- **Автозагрузка.** Влияние на время входа, шкала, отложенный запуск, массовая рекомендация.
- **Службы и задачи.** Тип запуска, планировщик, пресеты. Защищённые службы (Defender, брандмауэр, RPC, DHCP, DNS, журнал событий) заблокированы.
- **Реестр.** Двадцать проверенных твиков, живой обозреватель ключей с избранным, наблюдение за записями с лентой и счётчиками по процессам, вкладка «Границы» (что не предлагаем: Defender, UAC, SmartScreen, защиты процессора, проверка подписи драйверов).
- **Эффекты.** Живой предпросмотр анимаций, прозрачности, теней и задержки меню, пресеты.
- **Окна.** Холст с двумя мониторами, перенос мышью, привязка к 14 зонам, зазор, сохранение раскладок.
- **Мониторинг.** Ядра, процессы, сортировка, приоритет, завершение.
- **Изменения.** Журнал каждой правки системы с командами, откат одной записи или всех, скрипт для копирования.
- **Настройки.** Плотность, спокойный режим без анимаций, горячие клавиши (Ctrl+K, `g` + буква), копия и сброс.

**Модель.** Везде «черновик → применить → запись в журнале → откат». Пока не нажато «Применить», система не меняется. Настройки сети хоста не затрагиваются.

**Что в прототипе симуляция.** Всё. Показатели случайные с плавным дрейфом, реестр и службы выдуманные, команды корректного синтаксиса, но не выполняются. Оценки выигрыша (секунды загрузки, ватты) приблизительные. Реальный движок (Go, чтение реестра, служб, `powercfg`, `SetWindowPos`) ещё не написан.

**Проверено.** Синтаксис скрипта, jsdom: 77 проверок по всем экранам (клики, слайдеры, перенос окон событиями указателя, откат, горячие клавиши), ошибок JS нет. **Не проверено:** внешний вид и плавность в живом браузере на разных размерах, телефон, светлая тема.
