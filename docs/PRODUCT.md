# Чистовик: продукт, решения, критерии

Обновлено 24.10.2026. Подробности: [PLAN.md](PLAN.md) (этапы), [DESIGN-0.1.md](DESIGN-0.1.md) (журнал, откат, протокол), [FACTS.md](FACTS.md) и [COUNCIL.md](COUNCIL.md) (исследование и решения совета), прототип в `docs/prototype/`.

## Цель

Один владелец, один ПК на Windows 10/11 (x64, ARM64 собирается, на железе не проверяется). Чистовик снимает «ручную» работу над системой, но не рискует ею:
1. Находит и удаляет программы вместе с остатками, всё через карантин с откатом (релиз 0.2).
2. Центр управления системой: режимы, питание, автозагрузка, службы и задачи, твики реестра, эффекты (релиз 0.1).
3. Любое изменение записано в журнал и откатывается.

4. С 25.10.2026 акцент продукта: чистка и оптимизация Windows **с объяснением**: удаление программ любых видов, пакетов и обновлений, очистка диска, сироты реестра, вердикты по автозагрузке, службам и задачам, телеметрия и твики. Каждая находка отвечает «что это, зачем нужно, что будет, если убрать, как вернуть». Модули, границы безопасности и этапы C0–C4: [CLEANUP-SPEC.md](CLEANUP-SPEC.md).

Принцип: что программа не опознала точно, она только показывает и не меняет. Ошибка «не тронули» безопасна, ошибка «тронули» нет.

## Не цели

Антивирус, «ускорители» с обещаниями, чистка без объяснений и счётчики «найдено N проблем», «ремонт реестра» (есть только сироты с доказательством), облако, учётные записи, телеметрия, резидент в трее, управление чужими ПК. Не трогаем Defender, UAC, SmartScreen, защиты процессора, проверку подписи драйверов, сеть и DNS хоста.

## Критерии приёмки релиза 0.1

Проверяемы без живой системы (юнит и интеграционные тесты на подставных портах):
- Каждый запрос агента из белого списка проходит `StepGate`; неизвестный тип, лишнее поле, числовой enum, запрет Policy → отказ, в журнале запись `denied`, система не тронута.
- Для каждого вида шага (значение реестра, StartupApproved, служба, задача, схема и параметр питания) есть тесты: применение, повтор (идемпотентность), обрыв между `pending` и `done`, восстановление, откат, конфликт «изменено извне».
- Режим откатывается одной операцией.
- Негативные тесты `tests/Policy.Negative` зелёные и блокируют коммит.
- Подмена строки журнала не открывает запретную цель (цель при откате проверяется заново).
- Интерфейс: все экраны 0.1 имеют состояния пусто / загрузка / ошибка / нет прав (режим просмотра) / частичный результат; `--selftest` строит их без показа окна.

Проверяются позже в Windows Sandbox (до этого помечены «не проверено»):
- Значения твиков (`verified=false`), байты StartupApproved, схемы питания (включая Ultimate), поведение при симлинках HKU→HKLM, чтение WAL без прав записи, UAC-поток запуска агента, вид интерфейса на 100–200 % DPI.

## Планки качества

Отклик интерфейса на действие ≤ 100 мс; запись в журнал с `synchronous=FULL` не теряется при сбое питания; WCAG 2.2 AA для темы Signal (контраст текста 4,5:1, фокус виден, всё с клавиатуры, `prefers-reduced-motion`).
