# Чистовик 0.2.0: заметки о выпуске

Первая сборка, пригодная для живой проверки на Windows 10 (1809 и новее) и Windows 11. Подписи кода нет, публикации нет: пакеты лежат локально.

## Что в пакете

| Файл | Архитектура |
|---|---|
| `Chistovik-0.2.0-x64.msi` | x64 (Windows 10 1809+, Windows 11) |
| `Chistovik-0.2.0-arm64.msi` | ARM64 (Windows 11 on ARM) |
| `SHA256SUMS.txt` | контрольные суммы пакетов |

Пакеты самодостаточные: .NET ставить не нужно. Установка — `msiexec /i Chistovik-0.2.0-x64.msi` (или `/qn` для тихой), каталог `C:\Program Files\Chistovik`, ярлык в меню «Пуск». Обновление поверх 0.1.0 проверено, данные пользователя сохраняются.

## Что умеет

Чистка с объяснением по каждому объекту, удаление программ, автозагрузка, службы и задачи (с исключениями: часть служб и задач Чистовик не меняет), режимы, схемы питания и их параметры, 46 проверенных твиков, журнал с откатом. Изменения идут через агента с правами администратора (UAC один раз на сеанс), Core.Policy решает, что можно; без прав приложение работает в режиме просмотра.

## Что изменилось с 0.1.x

- Режим применяет твики, даже если схемы питания нет на устройстве (Modern Standby): схема пропускается, об этом сказано в результате.
- Программы, которые производитель запретил удалять (`NoRemove`), показываются только для просмотра.
- Тип значения в реестре, отличный от ожидаемого, не перезаписывается молча.
- Откат пересчитывается и после прерванного отката; журнал открывается без прав записи при работающей службе.
- Твики учитывают сборку Windows (`minBuild`/`maxBuild`) и редакцию; для отсутствующих значений заданы осмысленные «по умолчанию».
- Интерфейс: настоящие значки приложений, малые экраны (от 900×600), масштаб до 200 %, понятные сообщения об ошибках; на странице «Питание» значки схем переносятся на узком окне.

## Что проверено

- Автотесты (Core, Native, App, Policy.Negative, Integration): зелёные.
- Снимки интерфейса: 115 штук (размеры от 900×600 до 1920×1080, масштаб 96–192 DPI, состояния «пусто», «загрузка», «ошибка», «только просмотр», «частично»).
- Windows Sandbox (Windows 11 Enterprise, сборка 26100): применение и откат каждого твика, службы, задачи, диск, реестр, удаление программ, установка, удаление и обновление MSI, интерфейс через UI Automation.

## Что не проверено

- Windows 10: образа нет, проверялось по документации и модели каталога.
- ARM64 в запуске: пакет собран, архитектура файлов проверена, запущен не был.
- Modern Standby на реальном ноутбуке, два монитора с разным масштабом.
- Живой UAC и второй сеанс пользователя; запуск приложения и закрытие при обновлении в Sandbox скриптом не проверяются.
- Подпись: SmartScreen предупредит о неизвестном издателе до подписи пакетов.
- Часть твиков помечена «не проверено на живой системе»; реальное поведение Windows после их применения зависит от сборки.
- Журнал в режиме `journal_mode=DELETE` под антивирусом, который держит файл.

## Известные ограничения

- Гонка типа значения в реестре между проверкой и записью (узкое окно, отложено).
- Автозагрузка не показывает записи MSIX StartupTask и `Policies\Explorer\Run`.
