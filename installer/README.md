# Установщик Чистовика

Форма поставки по решению владельца: MSI на архитектуру (x64 и ARM64), self-contained, лицензия GPL-3, подпись позже (SignPath). Сборка: `powershell -File tools\build-release.ps1` (из каталога без кириллицы; на этом ПК это junction `C:\e\chistovik`). Результат: `artifacts\release\<версия>\` (вне Git): `Chistovik-<версия>-x64.msi`, `...-arm64.msi`, `SHA256SUMS.txt`.

## Почему WiX v5

- Нужен именно MSI: «Программы и компоненты», тихая установка `/qn`, обновление поверх (MajorUpgrade), корректное удаление. Это штатные возможности Windows Installer, а не самописного кода.
- WiX ставится локальным dotnet-tool (`.config/dotnet-tools.json`, версия 5.0.2) и расширения кладутся в `.wix/` репозитория; ничего не ставится в систему и не нужны права администратора. Inno Setup (EXE) потребовал бы установленный ISCC.
- Версия 5.0.2 закреплена намеренно: v5 распространяется по MS-RL без платы; WiX 7 вводит плату за поддержку открытого кода выше порога дохода (см. SKILL windows-exe-packaging).
- ARM64: `wix build -arch arm64` собирает MSI под ARM64 без железа (сам пакет на ARM64 не проверялся).

## Что делает пакет

- Per-machine установка в `C:\Program Files\Chistovik`. Каталог в мастере выбрать нельзя (WixUI_Minimal): Agent требует администратора, а канал App-Agent проверяет образ по SHA-256 и пути, поэтому каталог должен быть недоступен на запись обычному пользователю.
- В пакет входят все файлы `dotnet publish` (App + Agent в одной папке, как рядом лежат при разработке), без `.pdb`. Манифест Agent (`requireAdministrator`) не менялся.
- Ярлык «Чистовик» в меню «Пуск» (для всех пользователей), запись в «Программы и компоненты» (удаление; «Изменить» отключено).
- Мастер на русском: лицензия GPL-3 (RTF генерируется из `LICENSE`) с галкой согласия.
- Закрытие App при обновлении и удалении: `util:CloseApplication` (WM_CLOSE, без принудительного завершения). Agent не убивается; пока он работает, Windows Installer штатно предложит закрыть его или заменит файл после перезагрузки. При `/qn` в такой ситуации возможна отложенная замена файлов (параметр `REBOOT=ReallySuppress`, если перезагрузку не нужно предлагать).
- Данные пользователя (`%ProgramData%\Chistovik`: журнал, карантин, настройки) установщик не создаёт и не удаляет. Параметра «удалить данные при деинсталляции» пока нет (см. «Не сделано»). Вручную: удалить каталог после деинсталляции, но тогда пропадёт возможность отката по журналу.
- Версия берётся из `<Version>` в `Directory.Build.props` (суффикс предрелиза отбрасывается для MSI). `UpgradeCode` фиксирован в `Package.wxs`, не менять. Обновление между архитектурами идёт тем же `UpgradeCode`.

Тихая установка и удаление (ничего из этого на этом ПК не запускалось):

```
msiexec /i Chistovik-0.1.0-x64.msi /qn /l*v install.log
msiexec /x Chistovik-0.1.0-x64.msi /qn
```

## Подпись

Подписи нет. В `build-release.ps1` есть параметр `-SignCommand { param($Path) ... }`: вызывается для `Chistovik.*.exe/.dll` до упаковки и для каждого `.msi`. SignPath подключается там же (после одобрения проекта).

## Проверено и не проверено

Проверено: `build-release.ps1` собрал оба MSI из чистого состояния (x64 ~52 МБ, ARM64 ~47 МБ); `wix msi decompile` показывает 410 файлов, `Chistovik.App.exe` и `Chistovik.Agent.exe` в одном каталоге, ярлык, MajorUpgrade, CloseApplication, `.pdb` нет; `wix msi validate` (ICE) без ошибок для обоих MSI с отключёнными ICE38/43/57/60. ICE38/43/57 — ложные срабатывания на ярлык в общей папке «Пуск» с ключом в HKLM (для per-machine это корректно); ICE60 — предупреждение о языке не-шрифтового файла.

Не проверено: фактическая установка, обновление, удаление, ярлык и UAC; закрытие App при обновлении; поведение при работающем Agent; запуск на ARM64 (устройства нет); SmartScreen/Smart App Control для неподписанных файлов. Проверять только в Windows Sandbox (решение владельца), не на ПК.

## Не сделано

- Параметр `REMOVEUSERDATA=1` для удаления `%ProgramData%\Chistovik`: корректная реализация требует либо `util:RemoveFolderEx` с условием, либо кастомного действия, а проверить это без установки нельзя. Делать вместе с проверкой в Sandbox.
- Значок приложения и баннеры мастера: в проекте нет `.ico`.
